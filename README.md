# Debt Management BI

Operational Accounts Receivable Monitoring Platform.

## Current capabilities

- overdue control
- due-today monitoring
- upcoming payment monitoring
- branch-level operational monitoring
- hierarchical drill-down
- historical debt analytics
- behavioral indicators
- rating-based client prioritization

## Architecture

TXT / Excel
    ↓
Python ingestion
    ↓
PostgreSQL
    ↓
SQL analytical views
    ↓
NiceGUI frontend
